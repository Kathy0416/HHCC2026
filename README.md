# HackHarvard-MS
## 项目概述

这是一个将现有偏头痛记录网页应用转换为Android应用的项目。应用使用Capacitor框架（WebView）来加载和显示现有网页，同时提供类似原生应用的体验，并集成了Health Connect平台用于读取/写入睡眠数据。

## 主要功能

- **睡眠记录**：手动记录入睡/起床时间、睡眠质量
- **Health Connect 同步**：双向同步睡眠数据（从Health Connect导入，或导出到Health Connect）
- **数据分析**：图表展示睡眠时长、质量、时间段趋势
- **AI助手**：内置AI聊天功能，回答偏头痛和睡眠相关问题
